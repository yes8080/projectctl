# Greeting contract

REQ-HELLO: The function `Greet(name string) string` returns `Hello, <name>!`.
Leading and trailing whitespace in the input is removed. An empty or whitespace-only
name is rendered as `Hello, world!`. Unicode names must be preserved.

This is an example specification for local evaluation, not an approved requirement
for an existing user project. The user can authorize using this example as a baseline.
